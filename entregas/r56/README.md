# Descargas MRS Speech Analytics r56

Instalador Windows de 64 bits: [MRS_Speech_Analytics_r56_Instalar.exe](MRS_Speech_Analytics_r56_Instalar.exe).

Versión portable: [MRS_Speech_Analytics_r56_Portable.zip](MRS_Speech_Analytics_r56_Portable.zip).

Incluyen Python, dependencias y el modelo local Whisper small; no requieren conexión para instalar o procesar.

Los archivos se conservan sin cambios respecto de la distribución validada. Compruebe sus hashes en SHA256.txt. Los binarios Windows se probaron bajo Wine: instalación, permisos, transcripción local y reportes. No se probó una computadora física Windows.

No se incluyen audios de cuentas, checkpoints, reportes con datos de cuentas ni claves de administración.
