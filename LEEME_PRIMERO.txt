MRS SPEECH ANALYTICS - PROGRAMA r49

1. Extraiga TODO el ZIP en una carpeta nueva.
2. Abra INICIAR_PROGRAMA.bat dentro de esa carpeta.
3. Compruebe Version 3.6.19-r49 en la barra inferior.
4. Cree un proyecto, entre a Procesamiento por lotes y cargue audios y Excel.
5. Procese normalmente. Las reglas corregidas se aplican desde este proceso.

No necesita cargar un checkpoint para activar los cambios del programa.
Use el Python, las dependencias y el modelo local de Whisper que ya tiene instalado.

NO_APROBADO: incumplimiento ordinario comprobable sin dudas de seguridad pendientes.
REVISAR: evidencia insuficiente o incertidumbre que requiere aclaracion.
FALLA_GRAVE: conserva prioridad. No se aprueban llamadas para alcanzar una cuota.
Las copias NO_APROBADO van a NO_APROBADOS. El contador separa esos resultados.

Al finalizar se generan el reporte de calidad, las cuentas reetiquetadas y el
reporte adicional de motivos de no pago. Los originales no se modifican.
Las copias con cambio de estatus van a APROBADOS_ETIQUETA_CORREGIDA.
La tarjeta de Excel es la fuente del identificador de salida.

Esta entrega es el programa para su entorno Python existente; no es todavia
el instalador autonomo con usuarios y permisos. Consulte REVISION_49_PROGRAMA.md
y VALIDACION_R49.json para conocer comprobaciones y limitaciones.
